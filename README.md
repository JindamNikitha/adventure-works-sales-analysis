# Adventure Works Sales Analysis

Sales performance analysis of the Adventure Works dataset using SQL and Tableau, completed as part of my Data Analyst training with AIVariant/ExcelR.

## Overview
Analyzed sales, product, and regional performance to identify trends and top-performing segments.

## Key Findings
- Australia led all regions with ~31% of total sales
- Q4 was the strongest quarter, and December the best month
- 2013 was the peak year with 16.35M in sales
- Total sales: 29M across 28K orders

## Tools Used
- SQL (MySQL) — data cleaning and querying
- Tableau — dashboard and visualization
- Microsoft Excel — data modeling and datasets
- PowerPoint — presentation of findings
